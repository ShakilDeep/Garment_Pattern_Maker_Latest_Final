| a. Measurement writes skip range checks | P0-07 `b9bf485` | **Ranges:** each measurement now has its own plausible range, derived from its source-chart values: [0.5 × min, 1.5 × max], capped at 500 cm. This is the user's decision, because the sources define no ranges. A measurement with no source value keeps the blanket rule, 0 < v ≤ 500. **Enforcement:** bulk, scoped and assistant edits all go through one check. ## What P0-09 fixed

- **The e2e setup helper (`frontend/e2e/demo.ts`).** It restored the project through `localStorage`, but `startup.ts` deliberately always opens the Projects picker. The helper now closes the picker and chooses the run's project by id in the header's `Project` select. The workflow spec's reload step does the same by project name.
- **Stale e2e expectations, now visible for the first time since the baseline.** Each test keeps its intent:
  - The chest field showed `116`. That is the L value, and the form shows one decimal. The demo pattern is size M, so the correct value is `112.0` (2 × 56 cm).
  - The mixed-size marker spec now clears the M quantity, which the panel seeds for the current size. It then submits exactly `{S:2, L:1}`.
  - The upload input is labelled `Browse files`, the documented `browse-files` pattern.
  - "Cut quantity" now appears in both the info rail and the Studio inspector, so the spec takes the first match.
  - The zoom readout is the `Reset zoom` button, so the spec asserts its text is `110%`.
- **A real accessibility bug.** When the assistant was opened from the header launcher, pressing Escape dropped keyboard focus. The Close button already fell back to the header button and Escape did not. Both now share one restore-focus helper. Regression test: `frontend/src/copilotFocus.test.tsx` (red before the fix).
- **A real WCAG AA failure.** `--muted` text `#617187` on `--accent-soft` `#edf4ff` measured 4.49:1.
  - The new token `--muted-on-soft` (`#5e6e84`) measures 4.70:1.
  - It is used everywhere that pair occurred: `.badge`, the marker `.metrics` bar, and `small` text in hovered table rows.
  - `--muted` itself and the REF-004 layout are untouched.
  - The mixed-size marker spec now also runs axe on the rendered `.metrics` block, which the 8-screen scan never reaches because no marker exists yet when it runs.

## Known follow-ups (not Phase 0 blockers)

- **Input snapshots are stored in full.** Each one is about 54 KB per version, copied into history and undo. Store each snapshot once and reference it. (P0-04)
- **`check_operation` only reports.** It never blocks; `build()` is the actual gate. (P0-04)
- **Imports are blocked in NEEDS_INPUT.** A geometry import into a NEEDS_INPUT project returns 400. The cause is that `ALLOWED` forbids NEEDS_INPUT → PATTERN_NEEDS_REVIEW, which predates V6. (P0-06)
- **Measurement form wording is confusing.** The form takes full circumferences for the `half_*` keys, but the error quotes the half key and its range, always in cm. (P0-07)
- **Overrides saved before P0-07 can drift.** Overrides from before `b9bf485` have no `source_value`, so they fall back to `raw`. Re-importing the source re-anchors them. (P0-07)
- **Some tolerance cells break uploads.** A tolerance cell that Excel typed as a date makes the upload return 500 at save; nothing is persisted. A bool tolerance becomes 1.0. Fix this in the parser by keeping the raw text. (P0-08)
- **`/projects` is paginated.** The default page is 100 and the `X-Total-Count` header is gone. (P0-08)
  - The SPA reads only `items`, so beyond 100 projects the oldest silently drop out of the picker.
  - `repo.list()` still decodes every project before slicing.
- **Grading an older version replaces the current grades.** Grading version N with a list that includes the base size makes the grade-first rule show N's geometry for that size. The UI, the assistant and the exports all do this while `pattern` is newer. Decide the intended behaviour and pin it with a test. (P0-04 × P0-05)
- **409 codes are chosen by sniffing the message text.** "Project is archived" and "predates stored inputs" both return `REQUIREMENTS_NOT_READY`. Move to explicit codes, as `Unprocessable` already does.
- **The zoom readout's accessible name doesn't match its visible text.** It is labelled "Reset zoom" while it shows "110%", which breaks WCAG 2.5.3 (Label in Name, Level A). This predates V6.
- **The recovery spec only proves the seeded value survives.** It makes no edit before the forced failure, so unsaved edits are not covered. This predates V6.
- **Gemini and Groq are not wired in yet.** They are the chosen AI providers (keys come from the gitignored `.env`). The adapters land with the AI steps.
