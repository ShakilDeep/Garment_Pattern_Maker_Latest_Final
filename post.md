# LinkedIn post — Garment Pattern Maker V5

From a measurement workbook to a nested marker—without guessing.

I built **Garment Pattern Maker V5**: a demo-ready workspace that turns XLSX measurements and tech-pack PDFs into deterministic shirt patterns, grades, and cut layouts.

The flow is intentional:
Measurements → Requirements → Generate → Pattern Studio → Grading → Marker Nesting → Export.

What makes it different:
• **Deterministic drafting** — eight shirt pieces from explicit rules, not invented curves  
• **Source-true grading** — S through 3XL regenerated from workbook values  
• **Marker nesting** — fabric width, quantities, utilization, and prior-layout compare  
• **Honest AI** — the assistant proposes; you confirm; geometry stays rule-based  
• **Traceable exports** — SVG, PDF, JSON, and marker files with assumptions and input fingerprints  

Stack: React + TypeScript + Vite on the front; FastAPI + Python on the back; one Docker image for SPA + API (including Render).

This is a customer-demo system with clear boundaries—not a claim of production CAD certification. Calibration gates stay visible on purpose.
